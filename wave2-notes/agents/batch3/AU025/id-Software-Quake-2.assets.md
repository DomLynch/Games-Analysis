# id-Software-Quake-2 (asset audit, AU025)

Donor: /mnt/frankendom-donors/id-Software-Quake-2 (371 files). Source of Quake 2 v3.19: game/ (server-side game logic, monsters, items, weapons), client/, server/, ref_gl/ and ref_soft/ (renderers), platform folders (linux/, win32/, irix/, solaris/, rhapsody/, null/, unix/), qcommon/, ctf/ (capture-the-flag game module), baseq2/ (config and save folder only).

Halves: both code halves are in the box: the server-side game (game/, ctf/) and the client and engine (client/, server/, qcommon/). The data pack (baseq2 PAK with models, sounds, maps, textures) is absent: baseq2/ holds only config.cfg and save/. No .pak, .md2, .sp2, .wal, .pcx, .wav, .bsp or .dm2 file exists in the box (narrow find over the whole donor). The paired donor is not in the box: the Quake 1 folder (id-Software-Quake) is a separate game and its data pack is also absent.

## Inspiration (category level; GPL code and absent art)
- Latch-and-drain creature: the parasite has frame groups for a drain, a break-free, and a death chain (game/m_parasite.c lines 366, 390, 459). A creature that attaches to the player makes the threat a state (latched) as well as damage. Keep the latched state; change the silhouette and the drain cue.
- Hover-to-land creature: the hover craft has takeoff, land, forward and backward chains, three pain variants and a death chain (game/m_hover.c lines 127, 226, 232, 352). An airborne enemy that lands for close attacks is readable in a crowd. Keep the takeoff-land switch; change the hull.
- Defensive stance telegraph: the brain has a defense frame group and a duck group before its attacks (game/m_brain.c lines 244, 339). A visible guard pose before attacks is a telegraph the player can read. Keep the telegraph; change the posture and make the guard flash, not a head shape.
- Gib threshold: each monster has a gib health value; a hit that takes the monster below it plays a gib death with bone and meat pieces and a head, and a normal hit plays the ordinary death (game/m_parasite.c lines 475-478; game/m_brain.c lines 586-590). Keep the per-creature threshold as data; change the gib pieces to armour plates and sparks.
- Death clears status: brain_die clears its effects flag and power-armour type first (game/m_brain.c lines 586-591). A death resets active buffs so the corpse does not keep a glow.
- Item table with a reserved index 0 and classname strings (game/g_items.c lines 1134-1147, 1499). Data-first items: one row per item with a classname.
- CTF scoreboard as fixed-width columns (ctf/layout.txt line 3 and the format line below it). Numbers align in a text table; keep the column idea, change to icon columns at 375 wide.
