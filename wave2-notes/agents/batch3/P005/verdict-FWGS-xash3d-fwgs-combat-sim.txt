The autoaim mechanism as the code runs (sv_game.c 2257-2317):
- Default out is the view forward vector (2257).
- Trace from eye origin (origin + view_ofs, 2263) straight 2048 units (2267).
- Early return, keeping the forward vector, if that trace hits any entity and (it has takedamage AIM, or the shooter team <= 0, or the teams differ) (2271). So the assist only runs when the straight shot hits nothing or a teammate with team > 0.
- Threshold: bestdist = sv_aim.value when sv_allow_autoaim is set (2276-2277), else 0 (2278). Defaults: sv_aim "1", sv_allow_autoaim "0" (sv_main.c 25-26). With autoaim off the threshold is 0, a 90-degree half-cone. With autoaim on and sv_aim at its default 1, only targets exactly on the forward axis pass.
- Candidates: entities with takedamage == DAMAGE_AIM (2285), not fake clients (line not checked), not same-team when shooter team > 0 (2291), not self (2294). Aim point = bounding box centre (loop body, not quoted).
- For each: normalised direction, dot with forward; skip if below bestdist (2304); trace to the centre; if the first thing hit is the candidate (2309), take it as best and raise bestdist to its dot.
- Output: the best direction (2317).

Numbers are read from code. Not read: the game DLL that calls pfnGetAimVector; whether dead targets are excluded (sv_game.c 1011 clears takedamage on some edict, not read in context).

Best transferable idea: Snap an aimed shot to the best trace-visible target inside a dot-product cone, and skip the snap when the straight shot already hits an enemy.
