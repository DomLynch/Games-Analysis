Defects found (keep the idea, fix each):
- levelMin is documented as "inferred from getLevel() < N checks in STATE_CREATED" (types.ts 355) but the code scans the whole file (161-165). fix: scope the level gate to the start-state block, or store the gate per state.
- Reward window ignores branches. Any reward call within 20/5 lines of any exitQuest is summed (251, 273). Two alternative branches that each give the same item would double-count it. fix: tag each reward with its state or branch and grant only the branch that actually reaches the terminal exit.
- repeatable is taken from the first exitQuest match only (156-157). fix: one explicit repeatable flag in the quest data, not inferred from the first exit call.
- setItemsIds is read from the first match only (135). fix: collect every call (global match) if a quest declares more than one.
