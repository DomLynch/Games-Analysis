# R1: Open-source / RE / emulator code for old MMORPGs (client first)

Date: 2026-10-10. Method: GitHub search via `gh` (rate-limited, paced), `git ls-remote` on every git URL listed as verified, WebFetch of project pages, WebSearch. No binaries, assets or clients downloaded. Only links reported.

Headline: there is NO public CLIENT source (rewrite, decompile or leak) for any of the six games. The only client-side source code found is (a) the Return of Reckoning Lua UI source, (b) a third-party Asheron's Call 1 client (not AC2), (c) small WAR/RoR launcher/Vulkan-wrapper bits. Everything else is server emulators, data extractors or protocol parsers. No leaks found for any game (none flagged, none searched into: I did not look for leaked-source dumps on warez sites, only reported what public indexes show).

## Direct answers by game

- Shadowbane: server = MagicBane (open, Java, verified, MIT per README). Expansions (Rise of Chaos, Throne of Oblivion, Pirates, Redux): no separate code found; MagicBane server covers the final (post-ToO) game as far as it goes (I did not read its feature list). No client source, rewrite, decompile or leak found. The magicbane.com client downloads (tinyinstaller.zip, bigclient.zip, Textures.cache) are original binaries, not source; I did not fetch them. An Exetools thread (https://forum.exetools.com/showthread.php?t=20148) just links MagicBane Server; it is not a leak.
- WAR: most complete: ProjectWAR (very active) and WarEmu lineage, plus the RoR Lua UI source (client-side). Return of Reckoning's own server/client patches are not public; the "none of the original game's server code was used" statement is on its wiki https://wiki.returnofreckoning.com/Return_of_Reckoning . No client decompile found.
- Age of Conan: only ProjectFaolan (stalled sandbox). No client RE. Funcom still runs the game, so no "revival" scene.
- Darkfall: no code. SourceForge darkfallemu has no repository; 2012 blog is notes only. Rise of Agon is a live proprietary game.
- AC2: no public code found; emulator exists only as a Discord effort per a 2022 list that I could not corroborate beyond that. The "AC2D" client on GitHub is AC1.
- Albion / New World / Throne and Liberty: no emulators. Only protocol parsers (Albion), a .pak unpacker (New World).

## Not found / not verified / caveats
- Not searched in depth because tools blocked or limited: Reddit (r/emulation, r/privateservers etc.), RaGEZone (403), elitepvpers, MPGH, Gitee, GitLab, Bitbucket, Wayback, Hacker News. WebSearch is US-only and weak; GitHub search is the strongest evidence here. Absence of results is not proof of absence.
- GitHub search rate-limited me once; I paced queries. Private repos and self-hosted Gitea/Discord-only projects cannot be seen.
- ACEmulator, PhatAC, Magellan3 were only seen in search text, not ls-remote verified.
- BadBird/BattleBane (Magicbane Gitea) unverified (access refused).
- Throne and Liberty search by WebSearch was refused by that tool; only GitHub search covered TL.
- Many GitHub results for Age of Conan / Throne and Liberty / Shadowbane are free-download or cheat spam repos (MIT-licensed README lures). Treat as malware risk; none were opened or cloned.
- Licences: none of the code is licensed for copying into Dom's project except where stated (MagicBane MIT per README, AC2D GPL-2.0 which is incompatible with copy-in for most uses). Dom's rule (shape-only study) fits: use the RoR Lua UI source and AC2D for structure only.

## Short suggestion for the client camera/HUD/combat study
1. HUD: xyeppp/RoR-Interface (Lua/XML, current).
2. Client architecture shape: deregtd/AC2D (small C++ client).
3. Combat rules/data: MagicBane Server (Shadowbane) and ProjectWAR (WAR) server-side.
4. Camera: nothing found in open source for any of the six games.
