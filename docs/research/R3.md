Method: `gh search repos` (many queries), `gh api repos/<r>` for metadata (existence, licence, last push, size), README heads, `git ls-remote` for the non-GitHub and spot checks, plus web search. Nothing downloaded or cloned. Dates = last push on the default branch as reported by the GitHub API on 2026-10-10.
Flags: **[LEAK]** = repo hosts source of the original commercial game (client or server), shape-only study, do not ship; **[ASSETS]** = repo contains or needs game assets, do not fetch; **[AI]** = README says it is largely AI/vibe coded.

## C. What I could NOT find or verify

- **EverQuest Next / Landmark**: no leak, no code, no emulator. Daybreak said it retains all code and bans fan servers (MassivelyOP, 2017). Nothing on GitHub in my queries.
- **EQ2 / Vanguard client source or leaked source**: none. EQ2 only has server emu + the AoM redistribution above. Vanguard: asset extractor and a SourceForge stub, VGO Emulator source not public.
- **Lineage 2 leaked client source**: only the 2003 Chinese-hacker server source story and a Chinese-version rumour (elotrolado thread, hearsay). I found no repo hosting it. The only L2 "leak-derived" repo is dr3dd/L2Interlude (PTS data scripts).
- **Lineage 2 Revolution, Ragnarok 2 client, TERA client, Perfect World client/server source, Aion client**: nothing.
- **Forums (RaGEZone, elitepvpers, MPGH, otland, Reddit)**: those pages are login-gated or not indexed by my search tool; I only saw snippets (an elitepvpers SRO thread for "ZelosOnline emulator" open-sourced by its author, no link to a repo, and JaveQ Java SRO emulator, 2009). No downloads attempted. Leaked MU server sources (Deathway/Season sources) circulate there but OpenMU's README states it is NOT based on the "Deathway" decompile.
- **Gitee / Bitbucket / SourceForge / Internet Archive**: only one Gitee search (no relevant client found) and the vgemu SourceForge snippet. Not exhaustively searched. GitLab: shnok/l2-unity ok, no other relevant projects surfaced.
- **MuMain, Metin2Client, SourceFlyFF etc.**: I confirmed the repos exist and read README heads. I did not read the code, so claims such as "contains camera, UI, combat" are inferred from directory names/READMEs, not verified.
- **Licence labels are not reliable on leaks** (e.g. NakiuS/Metin2Client shows MIT). Treat every [LEAK] as proprietary.
- **eq-network**, godot-eqloader, Zeal: not individually verified (only search listing, or 404 for iamclint/Zeal).

## D. Suggested order for a camera / HUD / combat study (shape only)

1. MuMain / Main5.2 (real MMO client structure) [LEAK]
2. Metin2Client (second real client) [LEAK]
3. opensro (RE-driven port with docs + WebGPU camera)
4. l2-unity + gawric fork (camera collision, target frame, skillbar, nameplates)
5. RagnarokRebuildTcp (Unity RO combat/effects)
6. willeq / eq-client / eqoxide / OpenEQ / eqsage (EQ client behaviour, coordinate conventions)
7. MapleStory v83 clients for 2D HUD patterns
