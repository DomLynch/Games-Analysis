## Detail worth keeping

- **FLUX dev outputs.** I read licence section 2(d) on the Hugging Face copy: outputs may be used "for any purpose (including for commercial purposes)", but the model and any fine-tune are limited to Non-Commercial Purposes, and the definition (read on the GitHub copy) excludes revenue-generating use and using the model to train commercial models. So the two readings both exist. A LoRA built on Krea-dev would be a Derivative and non-commercial.
- **TRELLIS.2 dependencies.** DINOv3 License (Meta, [terms](https://ai.meta.com/resources/models-and-libraries/dinov3-license/)): no commercial ban, royalty-free, but requires a visible "Built with DINOv3" notice, no military/ITAR use, and passing the licence on if you redistribute. RMBG-2.0 ([card](https://huggingface.co/briaai/RMBG-2.0)): CC BY-NC 4.0 for self-hosted weights, commercial use needs a BRIA agreement; the card does not say whether cut-outs are cleared. nvdiffrast ([LICENSE](https://github.com/NVlabs/nvdiffrast/blob/main/LICENSE.txt)): NVIDIA Source Code License (1-Way Commercial), non-commercial use only; I did not confirm which TRELLIS.2 export step calls it (the card names it in a comment about mesh size, suggesting the GLB export path), so treat as UNVERIFIED but likely in the path. nvdiffrec licence not read. FlexGEMM, CuMesh, flash-attn licences not stated on the pages.
- **Changes versus R6.** Krea-dev outputs are not flatly "blocked" (R6 said so, and also said card wording was mixed; confirmed mixed). R6's "TRELLIS.2 is clean MIT" holds for the weights but not the whole pipeline. R6's Make-It-Animatable licence conflict is not a real conflict (MIT and Apache-2.0 are both permissive). R6's MoMask 404 was a typo in the repo name; it is MIT code. R6's guess that 100STYLE is Ubisoft is wrong; it is CC BY 4.0 from MIT/Meta/HKU authors.

## Summary for Dom (5 lines)

1. Safe to ship from today: FLUX.1-schnell and Qwen-Image (both Apache-2.0) and 100STYLE (needs a credit line).
2. TRELLIS.2 is MIT, but the pipeline pulls in DINOv3 (fine, needs a "Built with DINOv3" credit) and BRIA RMBG-2.0 (non-commercial: swap it out) and likely NVIDIA nvdiffrast (non-commercial software licence: get it checked).
3. Pixal3D is MIT but its dependency list was not readable, so read its NOTICE file before we ship anything from it.
4. Avoid: SAM 3D (silent on commercial use plus we would indemnify Meta), MoMask and Motion-X++ (trained on research-only motion data). Make-It-Animatable v1 is fine to test, but it is not our rig anyway.
5. 2D stage: use **Qwen-Image** as the main generator (cleanest licence, strong quality) with **FLUX.1-schnell** as the fast fallback; keep Krea-dev only for private look-dev, since its outputs are allowed for commercial use but the model and any LoRA trained on it are not, and that grey zone is not worth the risk for a shipped game. Not legal advice: have a lawyer sign off before release.
