## Leak and legal flags (shape-only study)

- RT4 530 clients (2009scape/Darkan), 317 refactors, RSC mudclient refactors, RuneStar, OpenRS2 deob: all Jagex-derived code. GitHub/GitLab permit them at present but Jagex has used takedowns before (RuneLite 2018). Study shape only, do not copy, do not vendor.
- fusion32/tibia-game: confirmed DMCA takedown by git itself. CipSoft is actively enforcing. otland threads claim it was a "leaked 7.7 server binary". Treat all derivatives (tibia-rust etc.) as unsafe.
- No "Tibia client source leak" that I could verify. Searches on otland.net returned only community reconstructions, old client archive links, and a Flash-client thread saying `.swf` can be decompiled with Sothink (commercial) but not recompiled. No Flash decompile repo found. `Leo32onGIT/TFS-Flash` NOT FOUND (private or deleted).
- LostCityRS Archive: index of caches/clients; underlying material is Jagex IP.

## Not found / not verified

- Zoom Extended / Zoom Extender plugin source: no repo URL found (only referenced by Camera Keys README). Locate via plugin-hub manifests.
- Rune-Server release threads (rev 377/614/667/718/742/900+ clients): not accessed; no GitHub-hosted refactors found for those revs apart from items above. Rune-Server pages were not fetched (blocked / not indexed by the search tool).
- RS3/NXT client RE: only binary patchers; no deobfuscated NXT source found.
- Project Insanity: no results.
- RaGEZone, elitepvpers, Gitee, SourceForge, Bitbucket, Internet Archive, Reddit: not searched individually (search tool returned only GitHub/otland/few mirrors). Gitee mirror of ClassicUO (gitee.com/long33/ClassicUO) was seen in search, unverified.
- Mabinogi: no open-source client found.
- GitHub API rate-limited mid-run, so licence/size for several repos (RuneStar, 317 refactors, TibiaAPI, OpenOSRS) are n/a.
- Last-activity dates and sizes come from GitHub API fields `pushed_at` and `size` (KB, repo size including history).
