# R4 report: open-source / RE / leaked MMORPG code (client first)

Date 2026-10-10. All GitHub rows verified with `git ls-remote <url> HEAD` (exists) plus `gh api repos/...` for size, licence, last push. Nothing was downloaded. Stars marked * were read from GitHub at check time. Reddit, RaGEZone, elitepvpers, MPGH, ownedcore, Gitee, SourceForge, Bitbucket and Internet Archive could NOT be searched directly (WebSearch only returned news and wiki pages for them); the GitHub search API was rate-limited (30/min, shared) for much of the run, so GitHub coverage is good but not exhaustive.

## Headline findings

1. The "mostly empty" SWG-Source submodules are not empty upstream. `SWG-Source/swg-main/.gitmodules` points at real repos, so `git submodule update --init` in the swg-main clone should pull them. Sizes per GitHub: `src` 47 MB, `dsrc` 123 MB, `client-tools` 354 MB (20,501 files), `serverdata` 1 GB, `mesh` 896 MB, `whitengold` 386 MB.
2. **`SWG-Source/client-tools` is the real SOE SWG client source** (leaked 2015, then cleaned and maintained). It has full camera code under `src/engine/client/library/clientGame/src/shared/camera/` (FreeChaseCamera, FreeCamera, CockpitCamera, ShipTurretCamera, StructurePlacementCamera, FlyByCamera). It also has `clientObject/.../camera/` (CameraController, GameCamera) and `clientGraphics/.../Camera.cpp`. The first thing to read for camera/HUD/combat shape. LEAKED, shape-only.
3. WoW: several live from-scratch clients exist (benilla/Rust+Bevy, WoWee/C++, WoWdot/Godot, WowUnreal/UE5). benilla has a dedicated camera module set (`crates/benilla-app/src/player/camera*.rs`, camera_dynamics, camera_water, camera_shake). WoWee has `camera_controller.cpp`, `wowee_camera_presets`. WoWdot has `cinematic_camera.gd`, `camera_shake.gd`.
4. Anarchy Online: `Inorien/AOReloaded` is a client mod (Ghidra RE) that adds a WoW-style camera (auto-follow, RMB-drag align, mouse-run). Direct RE of a real MMO camera.
5. City of Heroes: only server re-implementation is public (SEGS). No client code is public. The 2019 leaked server source was DMCA'd and is not (verifiably) mirrored on GitHub.

## Per-game notes and legal status

### Star Wars Galaxies
- Pre-CU / CU / NGE client + server source: the 2015 SOE leak, republished as SWG Source (SWG-Source org, rows 1, 15, 17-20). Leaked, proprietary SOE/Daybreak/Disney IP. Not authorised. No evidence of enforcement against SWG Source, but a press piece (PC Gamer/MassivelyOP coverage of 2026 SWG Legends incident) notes tolerance is tacit, not a licence. My search tool did not find a press article specifically about client-tools legality, so the legal assessment is my inference, not a verified source.
- SWG Legends, Restoration, Infinity: no engine source found. Legends' ecosystem on GitHub is player tools only (swgdui, swglogs, loadout tools). Infinity: SWGEmu-Private-Servers/SWG-Infinity (Lua, 2020) is a Core3 content derivative; others are launchers/wrappers (tdimino/swg-infinity). Recent news (2026-08) says a Reddit moderator decrypted SWG Legends' client assets with AI; those files are assets, not code, and I did not look for them.
- OpenGalaxies (opengalaxies/OpenGalaxies, C++, GPL-3.0, last push 2010-04-16) is an old from-scratch server attempt, not checked in depth.
- No Godot/Unity/Bevy port of the original client found. Only clean-room: SWGVulkanClient (#12), SWGEmuClient (Unreal, #13), swg-client-ts (#14).

### City of Heroes
- SEGS is clean-room BSD, server only. No public client. Segs-Client is a launcher, SegsEngine a stale Godot fork.
- 2019 leak: NCsoft source (server, then i25 binaries) leaked April 2019; Homecoming, Ouroboros (OuroDev), Rebirth, etc. built on it. NCsoft's one known action was a DMCA on the original i25 upload. Homecoming now holds an official licence (announced 2024-01-04) but does not share code. OuroDev published some server components (QueueServer) on its own site, not GitHub, and I did not locate a GitHub mirror of the leaked tree. If one exists it would be a DMCA risk. I could not verify more.

### Others
- Anarchy Online: CellAO (stale), AOReloaded (client RE, active). Project Rubi-Ka says it never saw Funcom source; its code is not public as far as I could find.
- The Matrix Online: mxoemu (2010) and Hardline Dreams (active C#, MIT). Both server-side.
- Auto Assault: nothing found on GitHub (only unrelated repos).
- Tabula Rasa: Rasa.NET and forks only (server). Stale versions from Google Code.
- DDO: nothing found (no emulator repo; only launcher DDO-ML and name-check tools).
- EVE: EVEmu server only. No decompiled client repo found (search returned zero).
- PlanetSide 1: PSForever (server + tools).
- Wurm: no open source engine; client/server mod loaders by ago1024 (unverified by ls-remote) and many mods. Wurm Unlimited has had no official update since January 2020 per one source.
- Ryzom: ryzomcore already held; osgcc/ryzom is a 2012 historical mirror.

## What I could not find or verify
- Reddit, RaGEZone, elitepvpers, MPGH, ownedcore, Gitee, SourceForge, Bitbucket, Internet Archive: not directly searchable with the tools available. SourceForge hits (AO4Free, SEGS site, AOCell) came up only as search-result titles.
- Any CoH client source, any Godot/Unity port of CoH.
- Any DDO, Auto Assault server/client code.
- Turtle WoW tooling beyond addons (Turtle's core is closed; only addon repos like ShaguTweaks and similar showed up).
- OpenWoW: no repo by that name surfaced.
- Exact licence of client-tools (none stated; it is leaked proprietary code).
- Contents of rows 13, 14, 27, 28, 32, 36, 48 were not opened.

## Suggested next steps for Dom's camera/HUD/combat study
1. In the existing swg-main clone, run `git submodule update --init src dsrc stationapi` (skip serverdata, ~1 GB). Fetch `SWG-Source/client-tools` separately (354 MB). Read `clientGame/.../camera/FreeChaseCamera.cpp` and `clientObject/.../camera/CameraController.cpp` first.
2. Read benilla's `player/camera*.rs` and AOReloaded's camera patch for modern MMO behaviour (auto-follow, RMB-align, mouse-run). Add Gethe/wow-ui-source for HUD layout and DynamicCam for situational camera rules.
3. Warcraft-Arena-Unity for a compact Unity combat/targeting reference.
