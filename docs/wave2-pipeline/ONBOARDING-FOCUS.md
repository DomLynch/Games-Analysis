# Onboarding focus (applies to every OB group; read after FEEL-TASK.md)
Topic widened by Dom (2026-10-11): the FIRST 30 MINUTES that hook a player, not only the first 5.
Frankendom's opening, for comparison only (do not critique it, find what donors do better or differently): the player is thrown into a gladiator-ring fight with strong combat, which is part of the story; wins the first fight; walks into the main town hall (bank and services); phone-first, 375 wide.
For each donor, from the code AND data AND string tables, report: (1) the first 90 seconds: what the player sees, does, and is told before any control; (2) first fight / first kill / first hit feedback and how it is staged or rigged to be winnable; (3) first reward, first loot, first level or unlock and how it is celebrated; (4) the first hub or town and how services (bank, shop, trainer) are introduced one at a time; (5) first meaningful choice; (6) the pull-forward hook at minute 5, 10 and 30 (a visible next goal, a locked door, a rival, a rumour); (7) tutorial style: forced, optional, or show-dont-tell, text length, skippable?; (8) drop-off risks it avoids or has; (9) 'could be ours at 20-30 percent resemblance' idea plus a 5-minute phone look test. Name the files/tables (tutorial scripts, starter-zone data, quest 1, intro cutscene, new-character setup). If the donor has no onboarding (library, engine only), say so in one line and pick the closest first-run code.
