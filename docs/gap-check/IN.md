# Gap check: IN (input, touch controls, camera)

Date 2026-10-12. Frankendom repo commit read: 8d6ae33a9 (read-only checkout). Topic folders found: IN001, IN002, IN003 (9 notes).

## Summary for Dom
- 9 donor notes by main call: 1 REUSE (OpenDiablo2 touch routing), 4 ADD (SRB2, veloren, Barony, teeworlds), 4 SKIP (flare, OpenMB, Mindustry, DevilutionX). The 3 stick notes plus flare's analog-pad part merge into one build.
- Reality check: none of the proposed target paths exist. There is no `src/fight/` folder at all. The real homes are `src/input.ts` (client stick and buttons), `src/touch-router.ts` (who owns a touch), `src/duel.ts` (engine intent step) and `src/sim.ts` (movement).
- Frankendom is a 1v1 duel with a stick plus action buttons and an always-face-the-foe lock. Tap-to-move and many-enemy targeting have no use in the duel; they only matter for the pit walk.
- Top 3 additions: (1) rescale the stick deadzone so it ramps from 0 instead of jumping to 0.12 (one merged fix from 5 notes); (2) a press counter so a tap during recovery is not lost (teeworlds); (3) a press-origin latch for hold-versus-move, only if tap-to-move is ever built (pit gate walk already has a tap pick).
- Licence: GPL and restricted donors below carry no numbers; ideas only, clean-room.
