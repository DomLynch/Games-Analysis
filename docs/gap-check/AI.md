## Merged additions (one build each)
- **G1 World chase state machine.** Notes: crawl, BrogueCE, cmangos (timer/leash), veloren, BehaviorTree (transition event). Build `suspect / hunt / search / return` on the existing `Mode` in origins/preview/mobs.ts, as written in mobs.md 2.3-2.7. Rules to carry: all clocks count server ticks, none wall-clock; seeded draws only, one stream per creature (mobs.ts already has `mixSeed`); a creature in `return` is not targetable and does nothing else; health refilled on arrival; the leash is a row field, bosses can be flagged "never breaks off"; the let-go clock runs from the last hit on this creature; the server decides, the client only plays it; a leashed creature cannot be pulled out of its zone row (zones as data). Preview flag first, as mobs.md section 8 says.
- **G2 Approach set and pack tactics.** Notes: CombatPathingRevolution, angband (ambush only). Build the radii dial, back-off, circle band and fall-back from mobs.md 5.5 as row data on the four styles; add a `pack_ambush` row flag. Rules to carry: ranged/caster rows are decided by style at load, not per tick; circle chance never falls to zero outside its band; null-check the row before reading it; no number is copied from a GPL donor. Group size stays inside the camp caps (mobs.md 3.3) and the MAX_ATTACKERS cap once that exists in code.
- **G3 Target stickiness for the pack token.** Notes: TrinityCore, cmangos. Do NOT build a threat table for the 1v1 duel. When the 2A token is built (combat-study.md:194), who holds it, and when it passes, needs one rule: keep the current holder unless a rival is clearly ahead, re-checked on the tick the lead appears, not on a timer. Rules to carry: server state only, the client gets the holder id and nothing else; dropped threat from an unreachable source is not banked; stacked taunts rank per source, not per effect (a donor defect); numbers come from our own battery, not the donors.
