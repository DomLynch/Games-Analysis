## Merged additions (one build each)
- G1 Effects budget for the phone. Notes: OpenGothic, Cubyz, ScummVM, Orbiter, OpenRCT2, Teeworlds, plus the decal count rows. Rules to carry: one table listing every pool (blood 112, sparks 24, witchfire 200, splats 12, wound spots 24, class pools) and their sum; a drop counter instead of silent overwrite; never delete an effect because the camera is far, just stop emitting; effects are client-only and never read by the fight step; sparks and blood still honour blood off. Add one test that fails when a pool grows without the table. OpenGothic (MIT) detail: size a pool as rate times lifetime. Report the counter in the existing per-fight beacon (src/perf-beacon.ts:15) so the real phone shows it.
- G2 Blood scaled by hit size and creature blood kind. Notes: Shattered Pixel, Half-Life SDK, Source SDK, otland, dhewm3. Rules: one scale number from damage share of max health, capped, aimed attacker to defender; the layer set (spray, drops, cloud) by a flag, not a new effect; blood kind (colour, mode) is a data field on the creature row, falling back to red; low blood setting stays one third. Seeded generator stays (blood-style.ts uses mulberry32) so replays match.
- G3 Origins corpse timeline. Notes: gawric L2J (Apache), LinCity. Rules: client-only, timed in sim ticks not frame time; nameplate off first, then fade, then removal; never earlier than the loot window and the kill-confirmed event; skip when no fade is possible; loot stays take-one and server-verified.
