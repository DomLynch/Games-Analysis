## Merged additions (one build each)
- G1 Zone-run registry (DOLSharp, EQEmu, l2dn, evennia, pokemonAutoChess, claudecraft, rathena, part of OpenXcom). One record per run: run id, zone id, owner key, members as ONE set (a leave for a non-member is ignored; all counts derived from the set), phase (loading, live, after, closed), created-at, hard-life end. Rules to carry: grace timer cancelled by an entry and re-armed by EVERY last leave; hard life starts at build, not at request; validate zone data before registering the run; timers are absolute due-times ticked by the server fixed-step loop, never separate wall-clock timers; the run id is server-chosen and never read from a client body; place comes from presence (where.ts), not the request; loading finishes on the server clock only. Numbers (life, empty grace, eject after death, warnings, max runs) are zone data fields.
- G2 Party entry and landing (EQEmu, keeperrl, claudecraft, rathena). Owner key is the server character id (or a party record once one exists); one live run per owner; a relog rejoins the same run; a removed member gets a short kick delay; a crossing party lands by entry side from zone landmarks and shows ONE leave-behind list the player confirms or cancels. Blocked by: no party record exists, and no ruling defines parties. Build only after Strategy rules party size.
- G3 Staged run with hand-off (OpenXcom, xu4, evennia). Stage chain stays in the encounter definition (world.ts:445); add per-stage carry rules (who stays, what drops) as data; the clear call is a server-verified kill via the existing settle path (encounter.ts:67-86), never a client flag; foes respawn fresh from the record on every entry; leaving pops back to the parent spot and clears the run; the run must not be used for the Pit.
- G4 Zone door channel (veloren). Server-side channel: starts only if the player is in range (standsWithin, where.ts:34), cancelled by range, hate list or state failure, fires once at end time; target is zone id plus spawn point from data, never a world position; companions move together only if they are in the same party/run.
